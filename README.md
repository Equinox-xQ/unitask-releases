# Unitasks

Unitasks is a Windows app that pulls everything you have to do from your university's
Blackboard, Canvas or Brightspace site into one schedule: due dates worked out from your class
times, priorities that rise as deadlines get close, reminders, and a grades overview.

## Download

Get **Unitasks-Setup-&lt;version&gt;.exe** from the
[latest release](https://github.com/Equinox-xQ/unitask-releases/releases/latest) and run it.
Windows SmartScreen may ask first: **More info → Run anyway**. After that, Unitasks keeps
itself up to date.

This repository only hosts the installers and the files Unitasks uses to update itself. The
"Source code" downloads GitHub adds to each release contain just this page.

Unitasks was called Unitask before version 1.3.2.
